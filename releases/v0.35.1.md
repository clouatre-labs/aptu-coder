## What's Changed

This is a PATCH bump shipping tool-output hygiene and metrics improvements: `exec_command` now strips ANSI escape sequences from command output so model-visible text is clean, and the metrics JSONL schema gains an `edit_count` field with the previously undocumented `batch_validation_failed` event now documented. The rest of the release is benchmark harness artifacts, CI duplicate-code detection, and dependency maintenance.

### Features

- **`feat(exec): strip ANSI escape sequences from exec output`** (#1602): `exec_command` output (stdout, stderr, and overflow captures) is now stripped of ANSI escape sequences, so model-visible text blocks are free of terminal control codes.
- **`feat(benchmarks): add v18 harness artifacts`** (#1608): Adds the v18 benchmark harness artifacts.

### Fixes

- **`fix(metrics): document batch_validation_failed and add edit_count field`** (#1595): Documents the previously missing `batch_validation_failed` metric event in docs/METRICS.md and adds an `edit_count` field to the JSONL schema.

### Documentation

- **`docs(benchmarks): fix MCP-arm wiring under --no-extensions`** (#1607): Corrects the MCP-arm wiring in the benchmark harness when running under `--no-extensions`.
- **`docs(audit): v18 benchmark readiness audit`** (#1606): Adds the v18 benchmark readiness audit per the docs/audit convention.
- **`refactor(tools): document spawn_blocking tuple result pattern`** (#1601): Documents the spawn_blocking tuple result pattern used in tool handlers.

### Maintenance

- **`ci(jscpd): gate on new clones via baseline ratchet`** (#1597): The duplicate-code scan now gates on newly introduced clones via a baseline ratchet.
- **`chore(ci): add report-only jscpd duplicate-code scan`** (#1596): Adds a report-only jscpd duplicate-code detection workflow.
- **`chore(deps): update rust crate rmcp to v3.4.0`** (#1592): Updates rmcp to v3.4.0.
- **`chore(deps): update github-actions`** (#1591): Routine GitHub Actions dependency updates.
- **`chore(release): bump workspace version to 0.35.1`** (#1609): Version bump for this release; no dependency changes.
